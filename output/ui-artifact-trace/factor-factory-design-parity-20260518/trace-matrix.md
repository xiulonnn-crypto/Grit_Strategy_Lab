## 允许偏差

- 当前真实 API `publishable_factors.length = 0`，因此页面按产品规则隐藏“可发布因子名单”。设计稿样例中该模块可见，导致漏斗卡、工作台、准入区整体上移 `256.531px`；这是数据状态差异，不是样式偏差。
- 最新需求新增 `F1 原始库` 只需 PIT 准入审计即可发布，因此实际准入规则为 4 列；设计稿原始样例为 3 列。宽度、高度、圆角、阴影与栅格间距已保持同一规格。
- 当前检疫历史 API 返回空结果，B3 列表显示真实空态；未插入 mock/sample 行。

## 内容完整性

- 搜索 `line-clamp` 与 `text-overflow`，未发现因子工厂模块使用强制省略截断。
- 固定高度面板保留内部纵向滚动：B1/B2/B3 均为 `760px` 外框，内容超出时在面板体内滚动。
- B1 任务类型、B2 一键送检、B3 日期/因子名/结果筛选、B4 一键发布条件展示均保留当前产品规则。
