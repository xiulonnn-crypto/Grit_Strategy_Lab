# T-002 - Seed Fixture And Live Acceptance Wiring

## Goal

Commit a minimal seed workspace plus manifest-driven live acceptance so Codex can verify real routes without relying on local runtime leftovers.

## In Scope

- Commit `seed_workspace.sqlite3`, `seed_workspace_market_data.sqlite3`, and `manifest.json`.
- Wire `web/scripts/run-live-acceptance.cjs` to read the manifest and inject live route IDs.
- Update `web/src/workspace.real-api.smoke.test.tsx` to consume env-driven IDs instead of hardcoded values.

## Out Of Scope

- Replacing the app's default runtime database behavior outside harness flows.
- Expanding live acceptance into a full browser suite.
- Cleaning or migrating historical non-harness SQLite files in other directories.

## Files Likely Touched

- `harness/fixtures/seed_workspace/seed_workspace.sqlite3`
- `harness/fixtures/seed_workspace/seed_workspace_market_data.sqlite3`
- `harness/fixtures/seed_workspace/manifest.json`
- `web/scripts/run-live-acceptance.cjs`
- `web/src/workspace.real-api.smoke.test.tsx`
- `.gitignore`

## Acceptance Checks

- `powershell -ExecutionPolicy Bypass -File .\scripts\codex-reset-fixture.ps1`
- `powershell -ExecutionPolicy Bypass -File .\scripts\codex-test-frontend.ps1 -IncludeLiveAcceptance`
- Confirm `web/src/workspace.real-api.smoke.test.tsx` contains no hardcoded `strat_*`, `run_*`, or `cs_*` constants.

## Rollback Notes

- Remove the committed fixture pair and manifest together if the harness fixture strategy is reverted.
- Revert the live acceptance runner and smoke test in the same change so the old ID contract cannot drift.
