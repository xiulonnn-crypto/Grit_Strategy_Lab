# T-001 - Repo-Level Codex Fixed Entrypoints

## Goal

Ship stable repo-level Codex entry scripts for fixture reset, backend verification, frontend verification, and smoke orchestration.

## In Scope

- Add `scripts/codex-reset-fixture.ps1`, `scripts/codex-test-backend.ps1`, `scripts/codex-test-frontend.ps1`, and the orchestrated `scripts/codex-smoke.ps1`.
- Write smoke reports into `harness/reports/smoke/`.
- Document the fixed entry flow in `README.md` and `TECHNICAL.md`.

## Out Of Scope

- Cleaning historical runtime artifacts already sitting in the repo root.
- Refactoring application runtime architecture or changing API behavior.
- Fixing unrelated frontend TypeScript debt beyond reporting it.

## Files Likely Touched

- `scripts/codex-reset-fixture.ps1`
- `scripts/codex-test-backend.ps1`
- `scripts/codex-test-frontend.ps1`
- `scripts/codex-smoke.ps1`
- `README.md`
- `TECHNICAL.md`

## Acceptance Checks

- `powershell -ExecutionPolicy Bypass -File .\scripts\codex-reset-fixture.ps1`
- `powershell -ExecutionPolicy Bypass -File .\scripts\codex-test-backend.ps1`
- `powershell -ExecutionPolicy Bypass -File .\scripts\codex-test-frontend.ps1`
- `powershell -ExecutionPolicy Bypass -File .\scripts\codex-smoke.ps1`

## Rollback Notes

- Restore the previous `scripts/codex-smoke.ps1` only if all four fixed entry points are being reverted together.
- Remove generated report conventions from docs if the report paths are rolled back.
